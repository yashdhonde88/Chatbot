
## 📌 Project Title
Simple NLP Chatbot using Python

---

## 📖 Project Description
This project is a simple **Natural Language Processing (NLP) based chatbot** developed using **Python**.  
The chatbot understands user input and responds using predefined intents and basic NLP techniques.

This project helps beginners understand how chatbots work in real life using text processing and pattern matching.

---

## 🎯 Purpose of the Project
- To understand basic **NLP concepts**
- To build a simple **text-based chatbot**
- To learn how machines understand human language
- To create a beginner-friendly AI project for resume and GitHub

**Example:**  
User: Hello  
Bot: Hi! How can I help you?
